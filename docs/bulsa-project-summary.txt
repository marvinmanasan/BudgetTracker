BULSA PROJECT SUMMARY
Updated 2026-11-02

Name: Bulsa. The lowercase bulsa wordmark is intentional.
Meaning: Filipino for pocket.
Tagline: A little room for what matters.
Purpose: A personal budget tracker for portfolio practice. Users manually record income, expenses and savings, set spending limits and review their records. It does not connect to banks or move real money.
Users: One person using their own device, including the developer. No admin/customer roles or cloud login in this milestone.

Platforms and delivery
Intended for iOS and Android through shared mobile code. Android is the required test and delivery platform. End goal: an installed APK that runs offline without Expo Go or Metro and keeps records across restarts. iOS support must be described as intended until tested. Website work comes later.

Tech stack
Keep the current Expo SDK 58, React Native, React, TypeScript, Expo Router and npm workflow. EAS builds the Android APK. Local SQLite is the planned storage module, to be verified against SDK 58 and installed by the learner. No backend or new framework is required.

Learning rules
I am a beginner and write all application code, configuration and tests myself. Give exact file locations, ordered tasks, learning keywords and tests. Start with hints in words. Review my pasted code by explaining the issue and pointing to it; do not rewrite it. Only give a tiny unrelated example when I explicitly ask. No full project files/functions. n means next; c means check. Review in batches. Each session is 90 minutes. Preserve my completed work and the removal of the practice-budget UI disclaimer.

Final retained feature list
- Monthly Overview with limit, expenses, remaining amount, separate income summary and savings preview.
- Manual expense and income entry with amount, category, date, payment-method label and optional note.
- Validation, save-in-progress, save failure/retry and success behavior.
- Activity grouped by date; search; month/type/category/payment filters; clear/reset; no-match and empty states.
- Transaction edit, delete and Undo.
- Monthly and category budget editing, near-limit and overspending messages, and automatic Everything else allocation.
- Monthly budget history and copying prior limits into a new month once.
- Savings goal creation/editing, separate contribution entries, empty goal and goal-reached states.
- First-use monthly setup, local display-name editing, local-storage/privacy information, and saved System/Light/Dark appearance.
- Local persistence, offline operation, readable mobile layouts and a tested Android APK with portfolio evidence.

Rules for calculations
Monthly remaining equals the selected month's limit minus expenses. Income does not automatically increase the limit. Named category limits plus automatic Everything else equal the monthly limit. Reject over-allocation, but allow actual overspending with a warning. Savings entries update the goal only; do not create duplicate expenses or change monthly remaining. New months copy limits once, without copying transactions or unused funds. Preserve historical month settings. Store money as integer centavos and group records by local transaction date.

Final screen list
Overview; expense entry; income entry; Budgets; monthly budget editor; category budget editor; Activity; filters; search/no matches; transaction edit/delete; Activity Undo; savings goal; goal editor; Record savings; first-use Overview; profile/settings; local-name editor; Appearance; data/privacy.
Shared states: invalid amount, overspent budget, storage loading/read failure, empty Activity, saving/save failure, category over-allocation, monthly limit below allocations, copied-month limits, goal reached, no savings goal and expense saved.

Visual direction
Warm light mode is the main design. Warm dark mode is the alternative. Preserve the supplied layout, round cards, modest Filipino identity, peso formatting and clear labels. Do not add decorative cultural imagery or new features.
